# firstpr documentation

Welcome to the docs for `firstpr`, the practice package for the
Python Open Source Workshop.

Documentation is often the *best* place to make a first contribution: it needs
no deep knowledge of the codebase, mistakes are low-risk, and clearer docs help
every future reader. In Session 4 you'll improve a docstring, build these pages
locally, and open a documentation pull request.

## Quick start

```python
from firstpr import greet, shout

print(greet("Ada"))        # Hi, Ada!
print(shout("hello"))      # HELLO!
```
