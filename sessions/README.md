# Workshop sessions

The curriculum, one folder per session. Work through them in order — each
builds on the last, and all hands-on work happens on this repository so you
experience the whole contribution lifecycle on a single project.

| # | Session | Core skills |
|---|---------|-------------|
| 1 | [Getting started in open source](01-getting-started/) | What contribution means, setup, first PR |
| 2 | [Finding projects & reading a repo](02-finding-projects/) | Discovery, issue triage, repo anatomy |
| 3 | [Git & GitHub for contributors](03-git-and-github/) | Fork/branch/commit/PR, merge conflicts |
| 4 | [Documentation contributions](04-documentation/) | Docstrings, Sphinx, doctests |
| 5 | [Packaging](05-packaging/) | pyproject.toml, wheels, TestPyPI |
| 6 | [CI/CD](06-ci-cd/) | GitHub Actions, linting, fixing failures |

Each folder contains:
- **`README.md`** — the teaching material (read/present this)
- **`exercises.md`** — the hands-on tasks with checkpoints

See [`../SCHEDULE.md`](../SCHEDULE.md) for the tentative timing.
